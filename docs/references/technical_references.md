# Technical References & Academic Attribution

**Project:** Reliability-Aware Anomaly Detection for Multivariate Sensor Data  
**Purpose:** Formal academic attribution of external baseline architectures, reference repositories, and theoretical frameworks.

---

## 1. External Reference Implementations

### CAROTS (Baseline 3 Reference)
- **Title:** Causality-Aware Contrastive Learning for Robust Multivariate Time-Series Anomaly Detection
- **Authors:** HyunGi Kim, Jisoo Mok, Dongjun Lee, Jaihyun Lew, Sungjae Kim, Sungroh Yoon
- **Venue:** International Conference on Machine Learning (ICML), 2025 (arXiv:2506.03964)
- **Reference Code Location:** `reference/CAROTS/` (Read-only research benchmark)
- **Repository:** https://github.com/kimanki/CAROTS
- **License:** MIT License
- **Attribution Statement:**  
  The CAROTS framework is utilized strictly as an external research baseline and benchmark execution environment. The proposed system (R-STNet) is an independent implementation featuring an explicit sensor-reliability estimation module and 4-way operational state discrimination engine.
