## 2. Detailed Technical Audit Findings

### 2.1 Feature Scaling and Standardization Audit
In `src/data/swat_loader.py` and `scripts/train_deep_model.py`:
* The scaler parameters $\mu \in \mathbb{R}^{51}$ and $\sigma \in \mathbb{R}^{51}$ were computed solely using the 39,744 normal training observations.
* The test set was standardized using these frozen statistics:
  $$X_{\text{test, scaled}} = \frac{X_{\text{test}} - \mu_{\text{train}}}{\sigma_{\text{train}} + \epsilon}$$
* *Finding:* No test statistics leaked into the normal training representations.

### 2.2 Threshold Calibration Protocol Audit
In `scripts/train_deep_model.py` (lines 266–275):
```python
# 6. Threshold Calibration on Pure Normal Validation Split (NO TEST LEAKAGE)
print("Computing validation anomaly scores for threshold calibration...")
val_scores, _, _ = compute_scores_batched(model, val_raw, args.model_type, device, window_size=args.window_size)
tau = float(np.quantile(val_scores, args.val_quantile))
print(f"  Calibrated decision threshold: tau = {tau:.5f}")

# 7. Blind Evaluation on Mixed Chronological Test Set
print("Evaluating test set with calibrated threshold...")
test_scores, _, latency_ms = compute_scores_batched(model, test_raw, args.model_type, device, window_size=args.window_size)
test_preds = (test_scores >= tau).astype(np.int32)
```
* **Audit Verification:** The threshold variable `tau` is completely frozen before `test_raw` is evaluated.
* The test set labels `test_labels` are only loaded into memory for metric computation *after* binary predictions `test_preds` have already been generated by applying the fixed threshold `tau`.
* *Finding:* Zero test label leakage. The threshold selection policy is 100% blind and leak-free.

### 2.3 Windowing and Temporal Causality Audit
In `src/preprocessing/windowing.py`:
* Windows are generated chronologically with `stride=1`.
* In `label_mode="point_end"`, the window label $y_t$ corresponds exactly to the final observation step $t$, preventing future leakages into the past representation.
* Train and validation sequences are processed independently to ensure that window lookback buffers never cross split boundaries.
